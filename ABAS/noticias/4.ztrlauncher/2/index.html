ZTR LAUNCHER (PC)

ZTR LAUNCHER é um app para PC, onde terá todos os downloads de aplicativos e Jogos oficiais para PC, Jogos e Apps da ZTR COMPANY.

La Sempre sairá os jogos mais rapidos pois a comunicação com o servidor é mais rapida comparada com o do site OFC DA ZTR COMPANY.

Sistema Usado

Bom o ZTR LAUNCHER foi feito com electron usando um servidor junto, bom não é muito bem um servidor mas é um arquivo .json onde ele tem algumas informações desde do titulo até o botao de download, então o index faz o request onde pega as informações que estão lá e tras para o APP ZTR LAUNCHER.

Projeto

Projeto iniciado dia 10/01/2025 e terminado dia 08/03/2025 e sendo atualizado constantemente até os dias atuais.
